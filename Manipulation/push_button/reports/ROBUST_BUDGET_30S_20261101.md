# 2026-11-01 robust探索予算10秒・30秒の比較

30秒・1候補20条件への変更を試し、探索予算だけを変えて比較した。
全条件を通過した候補数は増えたが、動作完了は10秒で6/6、30秒で5/6。
この結果を受けて30秒への変更は採用せず、コード・CLI・比較スクリプト・JSON例を
従来どおり10秒・20条件へ戻した。候補の検証・採点・実行制御の変更は行わない。
過去の10秒の測定は [従来の検証記録](ROBUST_PUSH_20261101.md)に残す。

## 条件と再現方法

基準コードは `47525c3`。Python 3.10.12、MuJoCo 3.14.0、G1 Menagerie、固定骨盤、oracle bbox。
8ワーカー、探索seed 0、1候補20条件、最大50候補・1000ロールアウトは共通。
評価seedは10002・10003。配置ずれ±1cm、校正ずれ±1mm、深度ノイズ標準偏差0.5mm。
同じseedの配置と観測誤差、探索用誤差条件が両設定で一致することをJSONで照合した。
両設定を順番に実行し、計測中に他方の探索を並行実行していない。

```bash
MUJOCO_GL=egl OPENBLAS_NUM_THREADS=1 \
  _local/button_press_yada/venv/bin/python Manipulation/push_button/sim/run_robust_suite.py \
  --controllers robust --seeds 10002 10003 \
  --planning-budget-s 10 --planning-scenarios 20 \
  --out _local/robust_push/budget_30s_20261101/budget_10s

# 最終の既定値は10秒のため、比較する30秒を明示する。
MUJOCO_GL=egl OPENBLAS_NUM_THREADS=1 \
  _local/button_press_yada/venv/bin/python Manipulation/push_button/sim/run_robust_suite.py \
  --controllers robust --seeds 10002 10003 \
  --planning-budget-s 30 --planning-scenarios 20 \
  --out _local/robust_push/budget_30s_20261101/budget_30s
```

出力先は新規ディレクトリが必要。生データは上記の出力先、集計は
`_local/robust_push/budget_30s_20261101/paired_results.json`。

## ボトル10002で確認した回帰

10秒では候補0を採用して完了。30秒ではスコアが高い候補4を採用したが、
シム内45.60秒の押下中に `Observed target shift exceeds certified correction envelope` で停止した。
ボトルの前方変位46.66mm、横変位約-4.77mmで物理的な押下量の条件は満たしたが、
画像からの横ずれ推定が5mmの補正上限を超えた。home復帰は未完了、制御解除は完了。

探索の物理評価は画像補正を加えずに固定軌道を評価し、ボトルの最終横変位は10mmまで許容する。
実行部は画像補正を加え、初回の対象位置からの横ずれを最大5mmで監視する。
この検証と実行の差により、探索スコアの高い候補が実行時に停止し得る。
30秒への設定変更では、この判定・採点・制御や停止閾値を変更していない。
