# ボトルの現場試行モード（2026-10-31）

`push-button` の頭カメラによるボトル押しに、`--profile field` とJSON設定、
保持・再計測・再開・復帰の操作、次回解析用の記録を追加した。
既定のプロファイルはstrict。ボタン入口と共有の `ArmMotion` は変更していない。
現場の操作例と設定項目は [BOTTLE.md](../BOTTLE.md)、
編集用の設定例は [field_trial.example.json](../real/field_trial.example.json) にある。

## 実機ログに対応した変更

| 実機で止まった条件 | fieldでの扱い |
| --- | --- |
| 台の前後辺の補正差が約10mmあり、4mmの整合条件を通らない | 対辺許容差を15mmにし、X・Yの基準辺を固定する。選んだ辺が見えなければ再計測する |
| 採用辺の切替で位置が跳び、3枚の位置が安定しない | 既定の基準辺はx_min・y_min。位置の安定幅は8mm、新しい異なる3枚を要求する |
| 脚速度の一標本の超過で終了する | まず保持する。100ms未満で戻り300ms安定すれば計測・接近中だけ再計測から再開し、継続すれば操作者の確認を待つ |
| 腰姿勢の変化で停止し、復帰も同じ監視エラーで遮断される | 校正とは別の試行開始姿勢から腰・IMU傾きを監視し、3度で一時停止する。再開・復帰は現状態から検査する |

元の再試行JSONを使い、保存された深度フィット結果を実際の `BottleLocalizer.consume` に渡して、
安定出力10回・位置不安定の棄却34回・出力sequence全件を再現した。
同じ保存座標のX補正をx_minに統一すると、安定44回・棄却0回となった。
位置の許容幅が4mmの場合にもこの結果を確認しており、辺の固定自体に改善効果がある。
元RGB-Dの再推論や、実機での押下成功を確認した結果ではない。

## 操作・制御・記録

- `CLI > JSON > プロファイル` の順で設定を適用し、使用値を表示・保存する。fieldの押す距離は既定20mm。
- YES入力後の現在の両腕で保持姿勢を取り直す。監視基準の取り直しでカメラ・手先の校正を書き換えない。
- 保持中と入力待ち中も監視を継続する。追従遅れがある場合、ブリッジの速度制限内で保持姿勢へ移る。
- `r` は古い対象位置を破棄して新しい3枚と現在姿勢から再計画、`b` は現在姿勢から復帰、`q` は終了。
- 押下開始後は再開を受け付けない。通信・不正状態・関節限界・追従・衝突の異常は再開可能な一時停止と区別する。
- fieldの終了コード0は押下指令・home復帰・解除の処理完了を表す。画像の距離評価と人による移動・直立の確認は別に保存する。
- 設定、校正、ソース・モデルの版、29軸の実測、送信できた指令とトルク、監視基準、停止再開イベントを残す。
  RGB-D・内部パラメータ・撮影姿勢は別スレッドの有限キューでNPZへ保存し、欠落・保存エラーを記録する。

## 検証

現場モード、実機入口、台認識、非同期認識、ボトル制御の重点テスト77件が通過した。
最終版のpush_button全体の回帰テストは370件通過（146.41秒）。
既存の歩行試験からTorchの非推奨警告3件が出たが、失敗・スキップはない。
実ソケットを使う既存試験は、ローカルソケット作成を許可した環境で実行する。

```bash
OPENBLAS_NUM_THREADS=2 OMP_NUM_THREADS=2 MUJOCO_GL=egl LIBGL_ALWAYS_SOFTWARE=1 \
__EGL_VENDOR_LIBRARY_FILENAMES=/usr/share/glvnd/egl_vendor.d/50_mesa.json CUDA_VISIBLE_DEVICES='' \
G1_MUJOCO_MODEL="$PWD/_local/bottle_push/menagerie/unitree_g1/g1.xml" \
/tmp/opencode/g1realistic/bin/python -m pytest -q Manipulation/push_button/tests
```

既存の追跡鮮度テストには、実装が0.75秒なのに0.501秒で失効を要求する不一致があった。
実装の0.75秒を維持し、テストを0.501秒で有効・0.751秒で失効する境界へ修正した。
台基準の失効は引き続き0.5秒で確認する。

実機への接続・動作は行っていない。次は現場の台と校正を指定して接触前確認を1回行い、
その後20mmの短い押下を3回記録して、移動・直立・復帰を確認する。
