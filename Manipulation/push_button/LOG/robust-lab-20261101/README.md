## 経路不採用の理由

`live/diagnostic_20261101_112438/result.json` は変更前の制御・評価方式での実画像由来の探索記録。
9.756秒で3候補を評価し、45試行を完走、11試行を接触判定で中止、4試行を期限で中止した。
採用候補は0本だった。

- 接触余裕は3mm超を要求したが、完走試行で最も良い値でも-0.589mmだった。
- 位置誤差をシミュレーション内の対象配置へ反映したうえで、余裕計算でも校正の不確かさ15mmを差し引いていた。
- ボトルの上下方向のずれも半径に対する余裕へ含めており、円筒の高さ方向の許容範囲を使っていなかった。
- 手前側へずらした誤差条件では、接触許可区間へ入る前に指先がボトルへ触れる予測が11件あった。
  `Unexpected arm contact: [72, 73]` のIDは `button_tip` と `robust_target_geom`。

この結果には評価実装の保守性・形状判定の問題が含まれる。実機での可否は未判定。

## 保存内容

- `setup/`: 当時の設定、前日の校正、操作者からの設置情報、準備状態。
- `live/`: 読み取り専用の接続確認、状態、認識・探索の試行記録。
  時間イベントは空のカメラpollだけを除いた。元データは操作PCの `_local/robust_push/lab_20261101/` に残している。
- `performance/`: 性能解析の集計、各並列数の生ログ、関数別計測、比較用の基準軌道。
- `simulation/`: 基準シーンのベンチマーク。実機の自由立位・接触を検証した結果ではない。
- `tools/`: 当時のローカル計測・起動スクリプトの写し。`_local` の配置を前提とし、そのまま実行する配布CLIではない。
- `validation/`: 中断時のテスト出力。
- `manifest.json`: コピー元と保存先、サイズ、SHA-256。仮想環境・重み・SSH設定・画像と生RGB-Dは含めていない。

JSON内の絶対パスは当時の操作PCの配置を表し、別環境での再現時には読み替える。
