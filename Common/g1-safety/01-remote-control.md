# 01. リモコン（R3）— 絶対に知っておくこと

出典: Unitree 公式「Remote Control」「Quick Start」（`../unitree-g1-developer/`）。

## 0. 最初に: バージョンでボタンが違う

ボタンの組み合わせは**モーション制御のバージョン**で変わる（公式がバージョン別のシールを配布）。
本資料は**新しい版（`Hold L2 + Click …` 系）**を基準にする。旧版は `L1 + …` 系で、同じ操作でも別のボタンになる。

- **自機のバージョンと、リモコンのシールを必ず確認する。**
- **緊急停止はダンピング。** 新版は `L2 + B`、旧版は `L1 + A`（公式の版別の記載）。
  **自機がどちらかを、最初に実機で判定する（§7）。判定するまでは、リモコンのシールで確認する。**

## 1. 緊急停止

| 操作 | 結果 |
|---|---|
| `L2 + B` | **ダンピング**。脱力して倒れる（バランスを失う） |

- **デバッグモード中も有効**。状態の暴走を防ぐ最後の手段。
- 立位では倒れるので、人が支えるか吊り下げておく。電源を切るのは最後。

## 2. モード

| モード | 意味 | 注意 |
|---|---|---|
| ゼロトルク | 全関節が脱力。振っても抵抗なし | 起動直後の状態 |
| ダンピング | 脱力だが、振ると明確な抵抗あり | 準備モードへ進める |
| 準備 | 5 秒で動作前の姿勢へ | 周囲を空ける |
| スクワット／着席 | 5 秒でゆっくり移行 | **バランス制御なし** |
| モーション | リモコンで歩ける通常状態 | |
| スタンディング | 指令ゼロで静止、乱れると歩く | |
| 連続歩行 | 常に足踏み | **非推奨** |
| デバッグ | SDK 用。**歩行制御が止まる** | 指令競合の防止 |

階段の昇降は**非対応**。

## 3. よく使うボタン（新版）

| 目的 | ボタン |
|---|---|
| ダンピング（緊急停止） | `L2 + B` |
| ゼロトルク | `L2 + Y` |
| ロックスタンド（準備） | `L2 + ↑` |
| 通常操作へ入る | `R1 + X`（1 自由度腰）／`R1 + Y`（3 自由度腰・推奨） |
| ラン制御へ入る | `R2 + A` |
| デバッグモード | `L2 + R2` |
| デバッグ確認 | `L2 + A`（診断姿勢へ） |
| 着席 | `L2 + ←` |
| 臥位 ⇔ 立位 | `L2 + X` |
| スクワット切替 | `L2 + A` |
| 立つ／歩く | `START` ダブルクリック |
| 低速／高速 | `L2` / `L1` ダブルクリック |

- `L2 + A` は、デバッグ中は「診断姿勢（確認）」、通常操作中は「スクワット切替」。
- **立位では、一部の組み合わせは 2 秒長押し**が必要。
- 連続歩行（`START` ダブルクリックで足踏み）は**非推奨**。

## 4. デバッグモードの入り方

1. **ゼロトルクかダンピングの状態**にする（それ以外では入れない）
2. `L2 + R2`
3. `L2 + A` で診断姿勢になれば、入れている（動画と違えば `L2 + R2` を数回）
4. 戻る・止めるときは `L2 + B`

- **吊り下げ**ておく。脚は支えられない。
- 起動するとモーション制御が自動で動き、**速度 0 の指令を送り続けている**。
  この状態で SDK を使うと競合して**ジッター**が出る。SDK は必ずデバッグモードで。

## 5. LED の色（モード確認）

| 色 | モード |
|---|---|
| 青 | 通常動作 |
| オレンジ | ダンピング |
| 緑 | 着席 |
| 黄 | デバッグ |
| 紫 | ゼロトルク |
| 濃い青 | スタンバイ |
| 赤 | **エラー** |

## 6. 運用の注意

- スクワットから通常操作へ戻すとき: `L2 + B`（ダンピング）→ 通常操作のボタン。
- 臥位・スクワット開始は**平らで硬い床のみ**。**ハンド装着機では使わない**。
- **10 分無操作で自動シャットダウン**（R3・スマホとも未接続の場合）。
- リモコンとバッテリーは満充電で使う。

## 7. 旧版・要確認

**自機の実測**（`rt/servicestate`）: モーション制御 `ai_sport` = **8.7.3.4**（稼働中）。
**版番号だけでは旧版か新版か判断できない。** 判定は実機で（吊り下げて固定し、2 人で）: `L2 + B` で脱力すれば新版、`L1 + A` で脱力すれば旧版。

| 項目 | 状況 |
|---|---|
| デバッグ中の `CheckMode` | 実機で `(0, {'form': '0', 'name': ''})`（成功・`name` 空＝通常コントローラ停止）。このとき `mode_machine`=5。`GetFsmId` は `(3102, None)`（戻りコード。ID は取れなかった）。通常モードの値は未確認 |
| 旧版の組み合わせ | ダンピング `L1 + A`、準備 `L1 + ↑`、ゼロトルク `L1 + B`、着席 `L1 + ←`（Quick Start の座位手順はこちら） |
| オフセット補償 | 公式どおり左＝`→`、右＝`←`、前＝`↓`、後＝`↑`（逆に見えるが公式の表記） |

自機のバージョンで動作を確認し、上の表に追記する。
