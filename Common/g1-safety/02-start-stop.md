# 02. 起動と停止 — 絶対に知っておくこと

二足歩行は本質的に不安定。**必ず手順どおりに**起動・停止する。

## 1. 電源を入れる前に

- [ ] リモコンとバッテリーが満充電
- [ ] 異物（水・油・砂・土）がない
- [ ] 緊急停止（新版 `L2 + B`／旧版 `L1 + A`）を知っている。自機の版は [01 §7](01-remote-control.md)
- [ ] 周囲に人・物がなく、床が平ら（吊り下げ・座位なら固定が確実）
- [ ] バッテリーは**無理に押し込まない**。「カチッ」で固定

## 2. 起動

1. バッテリーの電源ボタンを **1 回短く押し**、続けて **2 秒以上長押し**
2. 約 **1 分**待つ。全関節が脱力（ゼロトルク）すれば成功。**初期化中は触らない**
3. ダンピング → 準備 → 操作制御へ進む

| 起動方法 | 流れ | 要点 |
|---|---|---|
| **座位**（推奨） | ダンピング（`L1+A`）→ `L1+↑`（準備）→ `R1+X` | 肩を支えながら準備へ。※旧版の手順。新版は `L2+B` → `L2+↑` |
| **吊り下げ**（推奨） | ゼロトルク後 30 秒待つ → `L2+B` → `L2+↑` → 足を着ける → `R2+A` | 足が**着いてから**押す。安定後に吊り具を外す |
| **臥位** | ダンピング → 臥位⇔立位（新版 `L2+X`） | 起き上がる。**距離をとる**。ハンド機は不可 |

吊り下げの起動は「足首が限界に当たる音」で初期化完了。さらに 30 秒待ってから操作する。

吊り下げ: 肩の金具にロープを**固結び**。関節の絡みを確認。足を着けるまでロープは**徐々に**下ろす。

## 3. 停止

| 方法 | 流れ |
|---|---|
| **座位**（推奨） | 椅子の前に背を向けて立たせる → **肩を支えて**着席（新版 `L2+←`／旧版 `L1+←`）→ ダンピング → 電源長押し |
| **吊り下げ** | ロープに**張力**がある状態 → `L2+B` → 電源長押し |
| 立位（**非推奨**） | 保持して `L2+B` → 地面に寝かせる → 電源長押し |

- 電源は**2 秒以上長押し**。
- **立位のまま電源を切らない**（落下・破損）。
- 長期間使わないときは**バッテリーを外す**（クリップを両手で押さえ、ゆっくり）。
- 関節近くに**手を置かない**（挟まれ）。

## 4. 開発作業（テレオペ・SDK）

- 起動すると、モーション制御が**勝手に動き、速度 0 の指令を送り続ける**。SDK はこれと競合してジッターする。
- デバッグモード（ゼロトルクかダンピングから `L2 + R2`）で、これが止まる。`L2 + A` で確認。
- ただし**脚は支えられない**。公式の手順は**吊り下げ**（座位でのデバッグは公式に記載なし）。
- 2 人以上で作業し、1 人は緊急停止に手が届く位置にいる（推奨。公式の記載ではない）。
- テレオペの終了は **`q`**（腕が約 5 秒で初期姿勢へ戻る）。**`Ctrl+C` は使わない**（腕が戻らず制御が切れる）。
- 終了 → `L2 + B` → 支える／吊る → 電源 OFF。
