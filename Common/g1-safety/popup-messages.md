# UI ポップアップ文言（案）

Console のボタンを押したとき、**3 行程度**で出す注意。
詳細は [01](01-remote-control.md)・[02](02-start-stop.md)・[03](03-control-levels.md) を参照。

| ボタン | 注意（3 行） |
|---|---|
| **ダンピング（緊急停止）** | ・全関節が脱力します<br>・立っている場合は倒れます。人が支えるか吊り下げてください<br>・落下に備えて、足元と周囲を空けてください |
| 準備 | ・5 秒で立位の準備姿勢へ動きます<br>・ロボットの周囲に人・物がないか確認してください<br>・座位では肩を支えてください |
| 歩行開始（`R1+X`） | ・吊り下げている場合は、足が床に着いてから押してください<br>・床は平らで硬い場所にしてください<br>・階段の昇降はできません |
| デバッグモード | ・歩行制御が止まり、脚で体を支えられません<br>・吊り下げて固定してください（公式の手順）<br>・2 人以上で、緊急停止に手が届く位置にいてください |
| 着席・スクワット | ・バランス制御はありません。人が支えてください<br>・椅子の位置と、足元を確認してください<br>・ハンド装着機では使わないでください |
| 臥位 ⇔ 立位 | ・ロボットが自力で起き上がります。距離をとってください<br>・平らで硬い床のみで使えます<br>・ハンド装着機では使わないでください |
| 連続歩行 | ・止まらずに歩き続けます（非推奨）<br>・周囲に障害物と人がいないか確認してください<br>・止めるには `START` を押してください |
| テレオペ開始 | ・起動直後に両腕がゼロ姿勢へ動きます。周囲を空けてください<br>・吊り下げて固定してください<br>・終了は必ず `q`。`Ctrl+C` は使わないでください |
| 電源 OFF | ・立位のまま切らないでください（落下・破損）<br>・座位か吊り下げで、先にダンピングしてください<br>・2 秒以上の長押しが必要です |

## 方針

- 緊急停止（ダンピング）は**常に 1 操作**で押せる位置に置く。ポップアップは**押した後**に出す。**押す前の確認は入れない**。
- 現在のモードは LED 色でも示す（青=通常、オレンジ=ダンピング、緑=着席、黄=デバッグ、紫=ゼロトルク、赤=エラー）。
- ボタン表記はモーション制御のバージョンで違う（新版 `L2` 系／旧版 `L1` 系）。緊急停止は新版 `L2 + B`／旧版 `L1 + A`。自機の版を判定してから文言を確定する。
- ポップアップは 1 画面・3 行以内。詳しい説明はリンクで資料へ。
- 危険な操作（着席・臥位・デバッグ）は、現在のモードを確認してから有効にする。
