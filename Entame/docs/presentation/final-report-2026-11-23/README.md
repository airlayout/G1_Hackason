## ファイル

- `slides.html` が閲覧・投影画面。
- `deck.js` が各ページのタイトル、本文、発表者メモ、素材の指定。
- `formats.js` と `slides.css` が公開版から保存した描画処理とデザイン。
- `slides.js` がページ切り替え、投影、メモ全開の処理。
- `media/` が画像と動画。

本文や発表者メモを更新するときは `deck.js` を編集してブラウザーを再読み込みする。素材のURLは `/media/ファイル名` と記載し、対応するファイルをこのフォルダの `media/` に置く。
