# 東急不動産 社内フィジカルAI体験会 登壇資料（2026-09-24）

スライド・台本・ナレーション音声を一体で管理するためのディレクトリ。
`todochiji-hackathon-2026/projects/money-decision/slides.html` の構成を参考にしている。

## ディレクトリ構成

```
tokyu-fudosan-2026-09-24/
  slides.html                  # 提出・投影用スライド本体(台本を内包)
  scripts/generate-narration.py  # slides.html から台本を抽出しWAVを生成する
  audio/slide_1.wav ... slide_7.wav  # スライド番号と1対1対応するナレーション音声
```

## 運用ルール

- **台本の正本は `slides.html` 内の `talk-script` 。** 別ファイル(ピッチメモ等)を台本の
  正本として重複管理しない。
- 台本を直したら、必ず以下を実行して音声を作り直す。音声ファイルを手で編集・差し替えしない。
  ```bash
  # 事前にVOICEVOX ENGINEを起動しておく
  docker run --rm -p 50021:50021 voicevox/voicevox_engine:cpu-ubuntu20.04-latest

  python3 scripts/generate-narration.py
  ```
- スライド番号(`slide-number`)は音声ファイル名(`slide_<番号>.wav`)を決めるキー。
  途中にスライドを1枚挿入しても、番号を振り直さない限り対応関係はズレない。
- `audio/*.wav` はこのリポジトリにはコミットしない(生成物のため)。登壇前に手元で
  `generate-narration.py` を実行して用意する。

## ドキュメントの優先順位

このディレクトリの `slides.html` は「実装」層の最終成果物である。内容は
`Entame/docs/proposal/repeat-design.html`（PoC版企画書）を上流ドキュメントとしており、
矛盾があれば上流（企画書側）を正とする。企画の数値（対価1,500〜2,000円、3段階ミッション、
開発体制など）は企画書由来の「たたき台」であり、本番までに変更され得る。

## 内容についての注意

- 未実装の機能を既存機能として書かない（例: 人検知センサーによる自動回避は未実装であり、
  スライド上も「今後の検討事項」と明記している）。
- 未決事項（映像同意フロー・配布経路など）は、詳細を語らず前向きな方向性のみを短く示す。
