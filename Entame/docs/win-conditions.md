# 勝利条件の検討

リアル体験型ゲームの「勝利条件」を検討し、G1企画向けに3パターンへ絞り込んだ。

## 設計の基本方針

**目的（何をするか）**と**制約（G1に見つからない）**を分けて考える。

```
目的：宝を持って帰る／ボタンを押す／ゴールする  など
制約：G1に見つからない
```

目的側は極力シンプルにし、「G1に見られている」という制約だけでゲームの
難易度と緊張感を作る。目的側を複雑にする（謎解き等）と、
「G1の目を盗むゲーム」ではなく「謎解きゲーム＋G1」になってしまうため、
今回は謎解き系の目的を採用しない。

## 体験ゲームの基本パターン（一般的な整理）

| パターン | 勝利条件 |
|---|---|
| 持ってくる | 時間内に目的物を取得して戻る |
| 生き残る | 時間まで捕まらずに生き残る |
| 謎を解く | 時間内に謎・課題をクリアする |
| 通り過ぎる | 目的地まで到達する |
| 守る | 対象を最後まで守る |
| 追いかける／捕まえる | 対象を捕捉する |
| 指定場所に置く | 物を正しい場所へ運搬する |
| 作動させる | 指定された装置・ボタン等を操作する |
| 集める | 複数の対象を集める |
| 点数を稼ぐ | 制限時間内に最高スコアを出す |
| 見つける | 隠された対象を発見する |
| 騙す | 敵に気づかれず、注意をそらして目的を達成する |

## 絞り込んだ3パターン

### ① 盗む

**「時間内に宝を持って帰れ」**

`START → G1を避ける → 宝を盗む → G1から逃げる → START`

- 一番エンタメ性が高く、「盗む」という目的が直感的
- 現行企画（「G1の目を、盗め。」）をそのまま発展できる

### ② 逃げ切る

**「時間までG1に捕まるな」**

- 目的物なし、純粋なステルスゲーム
- ルールが最も単純で、PoCしやすい
- G1の「見る・追う・反応する」という挙動そのものを体験させられる

### ③ 突破する

**「G1に見つからずゴールせよ」**

- 「宝を盗んだこと」の検知が不要（ゴール到達の検知だけで成立）
- 技術的に実装しやすい
- 「G1の監視を突破する」というコンセプトが明確

## 除外したパターン

- **謎を解く**：ゲームの主眼が「G1に見られない」から逸れるため不採用
- **守る**：「参加者がG1に挑む」という今回の構図と合わないため不採用

## ワンフレーズ案

> 「盗む」「逃げ切る」「突破する」——G1の監視をかいくぐり、目的を達成せよ。
