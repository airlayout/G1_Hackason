# Safety — 人とG1が同じ空間に入るための条件

**このドキュメントは全員が読む。読んでいない人を現場に立たせない。**

体験中、プレイヤーは身長1.3mの人型ロボットと同じ空間にいる。
G1は倒れる。通信は切れる。**その前提で組む。**

---

## 絶対規則

1. **G1を人に向かって歩かせない。** 反応は旋回のみ。
2. **安全距離 2.5m（全方位）を侵されたら即停止。**
3. **ゲーム判定と安全停止を混ぜない。**
   ゲーム判定はカメラ（確率的、外れてよい）。安全停止は幾何（決定論的、外れてはいけない）。
   カメラが人を見失っても安全停止は効き続けなければならない。
4. **G1コントローラを持つ人を、操作する人とは別に1人立てる。**
   その人はゲームを見ない。G1だけを見る。
5. **通信が切れたらG1は止まる。** 動き続ける実装にしない。
6. **プレイヤーは走らない。歩行のみ。** 走ると転倒・衝突・安全距離の
   誤侵入のリスクが上がる。ルールとして開始前に必ず口頭で伝える。

---

## なぜ旋回だけなのか（実測値）

| 指令 | 実測 | 判断 |
|---|---|---|
| 前進 +0.5 m/s | +0.38（指令の76%） | ずれが大きい。人に向けない |
| 後退 -0.3 m/s | **転倒** | 学習範囲外。使用禁止 |
| 旋回 ±0.3 / ±0.5 / ±1.0 | +0.30 / +0.51 / +0.98 | ほぼ一致。**これだけ使う** |
| 静止指令 | 約0.04 m/s 漂う | 静止していても動く前提で余裕を取る |

旋回速度の上限は **1.0 rad/s**。上位のバグを実機まで通さないための最後の砦なので、
上限クランプ処理を迂回しない。

## リスクと対応

| リスク | 起きたときの状態 | 対応 |
|---|---|---|
| プレイヤーが安全距離に侵入 | 接触の恐れ | 幾何判定で即停止。運営が声で止める |
| 通信断 | 指令が届かない／状態が読めない | **過去に発生実績あり。** 1秒で停止に落とす |
| G1の転倒 | 周囲に危険 | コントローラ保持者が即座に脱力／電源断 |
| バッテリ切れ | 途中で停止 | 残量を毎プレイ前に確認。予備を用意 |
| 検知の誤り（誤検知・見逃し） | ゲームが不公平になるだけ | **安全には影響しない**。二系統に分けてあるため |
| 観客の乱入 | 想定外の人が視野・安全円に入る | 物理的な区画と運営の立ち位置で防ぐ |
| プレイヤーが走る | 転倒・衝突、安全距離への急な接近 | ルールで禁止。開始前に口頭で伝達、運営が現場で声をかける |

---

## 停止手段（多重化する。1つに頼らない）

1. **コントローラの停止操作** — 最優先。人間が最後の砦
2. **ソフトウェアの安全停止** — 幾何判定による自動停止
3. **通信断による自動停止** — タイムアウト1秒
4. **電源断** — 最終手段

---

## 開始前チェック（毎回）

- [ ] コントローラ保持者がいて、手にコントローラを持っている
- [ ] バッテリ残量を確認した
- [ ] 安全距離 2.5m の区画が床にマークされている
- [ ] プレイヤーに「G1に近づかない」を口頭で伝えた
- [ ] プレイヤーに「走らない（歩行のみ）」を口頭で伝えた
- [ ] 停止手段を1度試した
