# 実機テスト（5 分版）

期待値はすべて sim と計算の値で、**実機では未確認**。外れたら、その値を書き残す（それが sim と実機の差）。

## 始める前（30 秒）
- 電源に手が届く位置に立つ。変な音・端で押し続ける・何かに当たる、のどれかで即停止（Ctrl+C → 電源）。
- 台座を固定する。

## 1. 起動して向きを見る（1 分）
`python server.py --port <ポート名> --robot-id <校正ID>` で起動。
- 起動直後に腕が勝手に動かない。
- 画面のスライダーで肩・肘・手首を少し動かし、**Rerun の 3D（`python sim_replay.py <録画名>`）と同じ向きに動く**。

## 2. 従来の追従（1 分）
手を映して追従を開始し、手を止めて基準を取る。
- 基準を取る間、腕は動かない。
- 手に追従し、止めればブルブルしない。

## 3. IK 追従（2 分）
サーバーを再起動：`... --ik-follow`。腕を初期姿勢の近くに置き、肩・肘・手首の曲げの追従を ON にして開始。

| 確認 | 期待値 |
|---|---|
| 開始後 3 秒 | 腕がなだらかに動く（跳ばない）。肩 +20→約 -19、肘 +16→約 +62、手首 +69→約 +36 |
| 手を前へ伸ばす | 肘が伸びていく。ただし `limits.json` の肘の下限（49＝内部 -2）で止まる。先端 x 約 0.30 m まで |
| 手を下げ切る | 先端が机に当たらない（机の上 約 0〜1 cm） |
| 手を上げ切る | 肩が後ろ上へ振り上がらない |

逆向き・急な動きなら即停止。肘の下限を広げて伸ばし切る（肘 -63・肩 +71・先端 x 0.44 m）のは、机・台座・配線に当たらないと目で確かめてからにする（35 → 18 の順）。

## 4. つかむ（1 分、最大 5 回）
お菓子（x 0.24〜0.32 m が sim の成功帯）を置いて、真上 → 下げる → 閉じる → 持ち上げる。
- 成功の目安：3 回中 2 回。
- 失敗は「届かない／向き／滑る」のどれかをメモ。

## 5. 録画して sim と同じ動きか確かめる（+2 分）
追従の録画（カメラ映像＋関節の実測）は、サーバーが `debug/follow-<日時>.jsonl` に自動で残す。3 と 4 の動きがそのまま録れる。
1. 録画名（日時）を確認する：`ls debug/`
2. `python sim_replay.py <録画名> --open`（映像も並べるなら `--frames <フレームのフォルダ>`）
3. Rerun で見る。左：カメラ映像、右：3D のロボット。
   - 不透明 = 実機の実測の姿勢
   - 緑 = 今のコードを、同じ手の入力で sim が動かした予測
   - オレンジ = 手が求めた目標
4. 期待値：**不透明（実機）と緑（sim）の動きが重なる**。肘・肩・手首の曲げの向きとタイミングが同じ。IK のときは、伸ばすと実機も肘が伸びる。
5. ずれたら、どの関節がどちらへずれたかをメモする（向き・0 位置の違いの手がかり）。

撮った映像・フレーム・`debug/` は個人の映像が入るので、commit しない（git の対象外）。

## 終わったら
測った値（机の高さ・お菓子の位置）は `CRANE_PLAN.md` §2 に書く。

## 未確認のまま持ち越し
関節の 0 位置・向き、グリッパーの開き幅、伸ばし切り姿勢の干渉とサーボの保持、お菓子の摩擦・つかむ力。
