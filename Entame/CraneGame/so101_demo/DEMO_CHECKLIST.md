# デモ動画の検証チェックリスト

今日のデモ動画を撮るための、ゴール・定義・準備・手順・完了条件。README とは別に管理する。
コマンドは `so101_demo` フォルダで実行する（相対パスのみ）。

## ゴール

**SO-101 が、カメラの前の手の動きに合わせて、お菓子を1回つかんで持ち上げる。その様子を動画1本に残す。**

今日の範囲外: IK、奥行き、左右（台座の回転）。上下の動きとグリッパーの開閉だけを扱う。

## 定義

| 用語 | 意味 |
|---|---|
| 校正 | 各モーターの可動範囲を測る作業。これで関節の値が相対的な 0〜100% になる。模擬モードでは不要。 |
| 登録 | 次の4つの姿勢を記録すること。つかむ位置（低い）、持ち上げた位置（高い）、開いた幅、つかむ幅。 |
| 追従 | 手の高さで、低い位置と高い位置の間を動かす。指の開きで、つかむ幅と開いた幅の間を動かす。 |
| 録画 | カメラ1台の映像をそのまま保存する。認識点や操作画面は入らない。 |

## 準備

- [ ] SO-101 を Mac に USB 接続し、電源を入れる
- [ ] ポート名を調べる（`.venv/bin/lerobot-find-port`）
- [ ] ID を決める（例: `so101`）
- [ ] カメラを置く（手・爪・お菓子が一緒に映る位置）
- [ ] お菓子を1つ置く
- [ ] Chrome でカメラの許可を出す
