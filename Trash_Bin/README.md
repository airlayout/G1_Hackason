# Trash_Bin（ゴミ箱のフラップを押して、中を確認する）

警備員がトイレのゴミ箱を確認する動作（押して中を見る）を G1 にやらせる。矢田さんの提案（2026-11-03、Slack）。
対象は UiS のトイレのゴミ箱（ステンレス、36 × 25 × 59 cm、上面の浅いすり鉢の中央に、前後方向の軸で回るフラップ）。

**状態: MuJoCo で、腰を曲げずに、見つける → 押して開ける → 頭カメラで中を撮る → 戻る、までが通った（ゴミ箱は台に載せる）。実機用のスクリプト
（`real/push_bin.py`）も、ループバックの模擬ロボット（実機と同じ DDS・カメラの経路）で本番まで通った。実機は未確認。**
実機の手順は [real/REAL_PROCEDURE.md](real/REAL_PROCEDURE.md)。

## 流れ

1. ゴミ箱のおおよそ正面・1 m 以内まで来る（今は人がリモコンで。Navigation が実機で使えるようになったら地図の地点へ）
   → 頭カメラの深度でゴミ箱を測りながら、立つ位置まで少しずつ歩く（`lib/approach.py`、`real/approach_bin.py`）
2. 立った位置で、頭カメラの深度からゴミ箱の置き方（中心と向き）を測る（`lib/locate_bin.py`）
3. 深度で測った床から pelvis の高さを求め、押す点と、計画用の障害物（ゴミ箱の箱）を求める（`lib/bin_task.py`、`lib/bin_geometry.py`）
4. 腕の指令を始める。腕は両腕を下ろした姿勢から、体の近くで手を持ち上げてから前へ出す。腰は動かさない
5. 右手でフラップの右半分を真下に押し、指先が進まなくなったら止めて保持する（Button_Press/J1-gen の流れ）
6. 押したまま頭カメラで中を撮る。右半分が沈むと左半分が持ち上がり、その下のすき間から中が見える
7. 腕を戻して、指令を終える

押す流れ（IK・衝突の確認・押し込み・戻り・安全な終了）は [Button_Press/J1-gen](../Button_Press/J1-gen/README.md)
の `PressPipeline` / `ArmCommander` を **import して使う**。J1-gen のファイルは変えない。

## 構成

| ファイル | 内容 |
|---|---|
| `configs/bin_scene.yaml` | ゴミ箱の寸法・置き方・フラップ・中身、押す点、腰の傾き、手の衝突形状など。**値を変えるときはまずここ** |
| `lib/bin_geometry.py` | 置き方（中心と向き）から、押す点と計画用の障害物を求める。sim / real 共通 |
| `lib/locate_bin.py` | 頭カメラの深度から、ゴミ箱の置き方を求める。上面の深度で見つからないときは、フラップの「NO」のステッカー（白・つや消し）で求める（シミュレーションで中心 1.4 cm・向き 5° 以内。向きは粗い）。sim / real 共通 |
| `lib/lean.py` | 腰を傾けて押すための `ArmCommander`（J1-gen のものを継承）。既定は傾けない（`lean_waist_pitch_deg: 0`）ので使われない |
| `lib/bin_task.py` | 押す流れの組み立て（設定を J1-gen に当てる・床から pelvis の高さを求める・指の向きの候補）。sim / real 共通 |
| `lib/contents.py` | フラップを押し下げている間の深度から、中身がどこまで溜まっているかを測る（上面の高さと「空に近い・途中・満杯に近い・見える範囲には無い」）。sim / real 共通 |
| `lib/approach.py` | 測ったゴミ箱の置き方から、立つ位置まで歩く量（速さと時間）を求める。歩く前後の測定から、実際に動いた量も求める（指令との比を表示）。sim / real 共通 |
| `lib/hand_shape.py` | 計画とシミュレーションで使う手の衝突形状を、実際の手に近い小さな箱の集まりにする |
| `real/approach_bin.py` | 実機で、頭カメラでゴミ箱を測りながら立つ位置まで歩く（LocoClient。既定は dry-run） |
| `real/push_bin.py` | 実機で、見つける → 押す → 中を撮る → 戻る。段階を分けて試せる（見つけるだけ・dry-run・本番） |
| `real/REAL_PROCEDURE.md` | 実機の手順 |
| `sim/bin_scene.py` | MuJoCo にゴミ箱を置く（壁・すり鉢・ヒンジで回るフラップ・中身・押す点の目印） |
| `sim/push_bin_sim.py` | J1-gen の安全な計画で、押す流れを最後まで動かす（腕を動かす前に計画が通らなければ止まる） |
| `sim/view_bin.py` | 押す様子を MuJoCo の画面で見る（確認用。安全基準を満たさなくても動かして見せる） |
| `sim/approach_sim.py` | 立つ位置まで歩く流れを試す（シミュレーションは歩けないので、歩いた分だけゴミ箱を逆に動かす） |
| `sim/sweep_stand_height.py` | 台の高さ・距離・左右・本当の pelvis の高さを変えて、同じ悪条件で繰り返し、どれが安定するかを比べる |
| `sim/bin_robot_server.py` | J1-gen の模擬ロボットを、シーンをゴミ箱にして起動する（実機用スクリプトをこのマシンの中で試す） |

`lib/` という名前なのは、J1-gen のパッケージ名が `common` で、`Trash_Bin/common/` にすると import がぶつかるため。

## 使い方

環境は J1-gen と同じ（`G1_HuggingFace/venv` に `Button_Press/J1-gen/requirements.txt`、公式モデルは
`bash Button_Press/J1-gen/sim/fetch_models.sh`）。WSL でも WSLg で画面が出る。

```bash
# 画面で見る（ゴミ箱の手前に立ち、腰を曲げずに押す）
G1_HuggingFace/venv/bin/python Trash_Bin/sim/view_bin.py
G1_HuggingFace/venv/bin/python Trash_Bin/sim/view_bin.py --camera head_camera   # 頭カメラの視点で
G1_HuggingFace/venv/bin/python Trash_Bin/sim/view_bin.py --save-images _local/trash_bin/view  # 押し切った瞬間の画像も保存

# 安全な計画で、押す流れを最後まで（記録は _local/trash_bin/runs/）
G1_HuggingFace/venv/bin/python Trash_Bin/sim/push_bin_sim.py
G1_HuggingFace/venv/bin/python Trash_Bin/sim/push_bin_sim.py --locate          # ゴミ箱の置き方を深度から測る
G1_HuggingFace/venv/bin/python Trash_Bin/sim/push_bin_sim.py --locate --bin-front 0.25 --bin-yaw 3   # ずらして試す
```

立つ位置まで歩く流れ（歩行のずれもわざと入れる）:

```bash
G1_HuggingFace/venv/bin/python Trash_Bin/sim/approach_sim.py                         # 前 70 cm・左 5 cm・15° 斜めから
G1_HuggingFace/venv/bin/python Trash_Bin/sim/approach_sim.py --start 0.9 -0.15 -20 --then-push   # 着いたら押す
```

実機用のスクリプトを模擬ロボットで試す（実機とは混ざらない。ループバックだけ）:

```bash
G1_HuggingFace/venv/bin/python Trash_Bin/sim/bin_robot_server.py                       # 端末 A
G1_HuggingFace/venv/bin/python Trash_Bin/real/push_bin.py --network-interface lo --camera-config camera_sim.yaml --locate-only
G1_HuggingFace/venv/bin/python Trash_Bin/real/push_bin.py --network-interface lo --camera-config camera_sim.yaml --execute
```

画面の操作: `]` / `[` でカメラの切り替え（頭カメラ・手首カメラ（仮））、`Esc` で自由な視点、`3` で手の衝突形状を表示、
`Tab` / `Shift+Tab` で左右の欄を隠す。この画面はスクリプトが計算を進めるので、左の Simulation 欄の Pause・Reset は効かない。

よく使う引数（両方のスクリプト）: `--bin-front` / `--bin-y` / `--bin-yaw`（置き方）、`--lift-m`（台の高さ）、
`--inset` / `--from-axis`（押す点）、`--cam-pitch-deg`（頭カメラの下向きの角度）。

## 台の条件（腰を曲げない前提、2026-11-07 に MuJoCo で決めた）

安全のため腰は曲げない。その代わりゴミ箱を台に載せる。実物のゴミ箱は変えない。

| 項目 | 条件 |
|---|---|
| 高さ | **14 cm**（ゴミ箱の上面が床から 73 cm）。±1 cm で作る。pelvis の高さが 0.75 m と違えば同じだけ足し引きする（下の「高さの合わせ方」） |
| 上面の大きさ | ゴミ箱の底（36 × 25 cm）とほぼ同じか、少し小さく。**ゴミ箱の外にはみ出さない**: 床の平面は「床の高さ ± 15 cm」の点で合わせる（`lib/locate_bin.py` の `_floor_level`）ので、はみ出した台の上面（床から 14 cm）が床と混ざるおそれがある（シミュレーションは同じ大きさでしか確かめていない）。ロボット側の面はゴミ箱の正面にそろえ、手前に出さない（つま先と膝に近づく） |
| 固定 | 押してもずれない・傾かない。ゴミ箱が台の上で滑らない（シミュレーションでは完全に固定している） |
| 置き場所 | ゴミ箱の正面が pelvis の前 23.5 cm（つま先の前 9 cm、膝の前面の前 7 cm）、中心が体の中心から右へ 15 cm、正面を向く |
| 周り | ゴミ箱の上面と同じ高さの物を近くに置かない。ゴミ箱の周りの床が頭カメラに写る（床で高さと傾きを測るため） |
| 後ろの壁 | **30 cm 以上離す**（実物は壁に付けて置いてあるが、デモでは台ごと離す）。押す流れ（悪条件 24 回）: 壁なし 22、30 cm 21、20 cm 18、10 cm 12、3 cm 11、0 cm 5。立つ位置ではゴミ箱の手前の縁が頭カメラの視野の下に切れ、前後の位置は後ろの縁だけで決まる。後ろの縁が壁に近いと、深度のノイズで壁と見分けられず位置が 2〜10 cm ずれる（2026-11-07、MuJoCo） |

**高さの合わせ方:** 効くのは pelvis から見たゴミ箱の高さ。実機で `--locate-only` を実行すると「床から求めた pelvis の高さ」が出るので、
台の高さ = 14 cm +（その値 − 75 cm）にする。pelvis 0.73 m + 台 12 cm は 23/24、0.77 m + 台 16 cm は 22/24 回成功した。
台を変えられないときは、`pelvis_height_m` が測った値に置き換わるので計画は合うが、0.77 m のままだと 18/24 回に下がる。測った床が設定と
4 cm より違うと、測り間違いの可能性があるので止まる。

## 結果（2026-11-07、MuJoCo）

実機の膝の実測 35° の立ち方、腰 0°、J1-gen の安全基準のまま（すき間 1 cm・関節 0.5 rad/s）。悪条件は試行ごとに変える:
立つ位置 ±2 cm・±5°、上面の深度の欠け 0〜60%、深度のノイズ、頭カメラの本当の角度 43〜49°、較正のずれ ±1 cm。
`sim/sweep_stand_height.py` で再現できる（全 512 回 + 検証。結果は `_local/trash_bin/stand_sweep/`）。

| 台 | 正面 22 cm | 正面 23.5 cm | 正面 25 cm |
|---|---|---|---|
| 12 cm | 22/24 | 18/24 | 5/24 |
| **14 cm** | 19/24 | **23/24** | 18/24 |
| 16 cm | 14/24 | 21/24 | 21/24 |

- 左右は −15 cm（どれも同じ 24 通りの悪条件）。4 cm と 20 cm 以上は、1 回目の総当たり（左右 −15 cm、正面 19〜28 cm、各 8 回）で 1 度も成功しなかった
- **14 cm・23.5 cm の詳細:** フラップの角度は中央値 45°、最小 30°。フラップ以外への接触なし。深度で測った位置の誤差は 1.7 cm 以内
- **中の見え方（同じ 23 回の成功のうち）:** 赤（左側に置いた中身）とコップの両方が各 100 画素以上で写ったのは 14 回、どちらかなら 21 回。
  ゴミ箱は画面の右下に寄り、奥の手前側は切れる。中がはっきり見えるとは言えない
- 着いたあと押す流れ（`approach_sim.py --then-push`）は既定の条件で 1 回通った。悪条件を入れた繰り返しは、この置き方ではまだしていない

| 以前に確かめたこと（別の置き方。参考） | 結果 |
|---|---|
| 立つ位置まで歩く（歩行のずれ ±25%・横すべり 15% を入れて） | 前 0.5〜1.1 m・左右 ±30 cm・±25° の 6 通りから、5〜9 回で着いた。最後のずれは 1.4 cm・0.8° 以内 |
| 頭カメラの角度 | 実機は通常 約 45°（J1-gen の記録。URDF は 47.6°） |

## 分かったこと（なぜこの形か）

- **正面から押すのは、頭カメラで中を見るため。** 体の右横に置けば楽に押せるが、頭カメラに写らない。
  手首カメラは付ける時間がなく、頭の上の前向きカメラ（ちょんまげカメラ）は下が見えない
- **立ち方は実測から決めた。** 膝 34.9° / 36.1°（Navigation/nav2_stable/findings/g1_dds_sensors.md §10.5）。pelvis の高さは資料で割れている
  （膝から 0.762 m、LiDAR の高さから 0.741 m、深度の床から 0.73 m）ので 0.75 m にして、実機では床から測り直す。
  公式モデルの 0.793 m は脚を伸ばし切ったときの値
- **台は低すぎても高すぎても通らない。** 低いと腕が届かず、高いと手首がゴミ箱の手前の縁に近づいたり、押す深さが足りずフラップが開かなかったりする
- **指は前へ傾ける。** 真下に向けると手首（`wrist_pitch`）の可動域が足りない
- **押す点はフラップの軸から 5 cm。** 2.5 cm だと手の幅が軸をまたいで反対側の半分も押し、約 19° で止まった
- **手の衝突形状を小さな箱の集まりにした。** J1-gen の「手全体を包む箱 1 つ」だと、開口に手を入れると実際は当たらないのに
  「すき間 1 cm を割る」として計画が通らなかった
- **指先が進まなくなったら止める。** 決めた深さまで押し続けると、フラップが逃げたあとも押し付けて 80 N 以上になった。
  止める基準は J1-gen の 5 mm ではフラップが開き切らず、10 mm にした
- **シミュレーションの脚の注意。** pelvis を固定すると、MuJoCo が親子のリンクの接触を無視しなくなり、脚を曲げた立ち方で股関節が弾かれて
  足が後ろへ流れた。`sim/bin_scene.py` で pelvis と太ももの付け根の接触を外してある

## バランスの根拠（2026-11-07 に記録と計算で確認。実機では未確認）

モデル（33.3 kg）で、腕を下ろした姿勢からの重心の前へのずれを計算し、実機の記録（Button_Press/J1-gen、`origin/Dev/ButtonPress` の
`real/DAILY_LOG_20261103_laptop.md`）と比べた。実機の姿勢は記録の指先の位置から IK で再現した推定（高さは z +0.14 m と仮定）。

| 姿勢 | 重心のずれ（前） | 実機の体の動き |
|---|---|---|
| 11/3 空中 40 cm | +11.9 mm | 1.8 mm・0.24°、足は動かない |
| 11/3 空中 48 cm | +17.7 mm | 2.7 mm・0.49°、足は動かない |
| **ゴミ箱 全行程の最大** | **+17.8 mm**（押す力 4 N は約 +5 mm 相当） | 未確認 |
| 11/3 空中 50 cm | +20.4 mm | 3.6 mm・0.54°（「若干傾いた」）、足は動かない |

- 空中の試験はハーネスあり、40〜50 cm で 7 回送った。押す力は掛かっていない
- 10/31 には、計算上のずれがもっと小さいボトルで、体が 65 mm 前へ動いた回と、84 mm・7.5° 傾いた回がある。原因は不明（トルクの記録が無い）で、
  重心だけでは説明できない。腕を伸ばしたまま Enter を待つ間に増えた。同じ広げた設定は 11/1 に体の傾き 1° 以下で動いた
- 公式の資料に、腕をどこまで出してよいかの数値は見つからなかった。公式の腕のサンプルは「吊り下げて Lock Standing で試す」を勧めるが、
  Lock Standing はバランス制御なし（`Common/unitree-g1-developer/24_sport_services_interface.md`、`origin/docs/g1-safety`）なので、吊らずに立たせるときは使わない
- 体が乱れると足を踏み出す可能性がある。ゴミ箱はつま先の前 9 cm なので、周りに人や壊れる物を置かない

## 実機の前に必要なこと

- **台を用意する。** 条件は上の「台の条件」。高さは `--locate-only` で実機の pelvis の高さを測ってから決める
- **バランスを確かめる。** シミュレーションは pelvis を固定しているので、下の「バランスの根拠」は記録との比較で、実機の確認ではない。
  最初はハーネス付きで、ゴミ箱なしで腕だけ動かし、`body_motion.csv` を見る
- **実物の深度を撮る。** ステンレスの鏡面なので上面の深度が欠けやすい（矢田さんの指摘）。`lib/locate_bin.py` に通して確かめる
- **フラップの重さ・戻る強さを測る。** シミュレーションでは弱いばね（0.05 N·m/rad）で近似している
- **頭カメラの向きを確かめる。** 作業の初めに J1-gen の `real/check_head_tilt.py`（日によって首が傾いていることがある）
- 手順は [real/REAL_PROCEDURE.md](real/REAL_PROCEDURE.md)（見つけるだけ → dry-run → 本番）
