カメラ映像

lidar（点群）

確認中…

停止中

Jetson の lidar_stream.py（rt/utlidar/cloud_livox_mid360 を購読するだけ。モーターには触れません）の点群を中継して表示します。1 フレーム（0.1 秒）は元々まばらな走査なので、直近の数枚を重ねると壁や床の形が見えてきます（G1 が静止しているとき向き。歩行中は尾を引きます）。生は約 20k 点（うち有効なのは約 11k）・10 Hz で、「点の細かさ」で Jetson 側の間引きを選べます（粗 0.4 MB/s・標準 0.9 MB/s・全点 1.8 MB/s）。ドラッグで回転、ホイールで拡大縮小。色は高さ（青＝低い、赤＝高い、重ねた全点での相対値）。座標は livox_frame（lidar 原点・単位 m）のままで、G1 の向きに対して傾いている可能性があります。円は距離（m）、赤線が x 軸・緑線が y 軸。タブを離れると取得を止めます。
