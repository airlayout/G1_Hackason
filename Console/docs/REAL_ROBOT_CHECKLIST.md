PR #30（`Dev/UI` 向け）は、この一覧の **A〜C が済むまでマージしない**。
安全手順は `Common/g1-safety/`（2 人以上、`L2 + B` に手が届く、周囲を空ける、吊り下げ／着座から）。
結果は各行の `[ ]` に日付と値を書き込み、`docs/G1_FINDINGS.md` の未確認リストから消していく。

`python3 Console/server.py --host g1-ts` を起動し `http://127.0.0.1:18790/` を開く。

## H. カメラ（旧 `NEXT_CHECKLIST.md` から移管。G1 は電源オン、手動起動・停止のみ）

先に「実機なしで分かったこと」を `G1_FINDINGS.md` §15（他班 PR #34 の実機調査）に記録した。
D435i の RGB は、OpenCV で `/dev/video4` を開く方法をやめ、**公式 `VideoClient.GetImageSample()`** に切り替える方針（PR #34 で 1920x1080・300 秒連続を確認済み）。

| # | 確認 | 合格条件 | 結果 |
|---|---|---|---|
| H1 | `VideoClient.GetImageSample()` で RGB を取り、コンソールのカメラタブに出す（`camera_stream.py` の取得元を差し替え） | 1 分連続で映る。取得失敗は 5 秒以内に復帰または停止 | [ ] |
| H2 | `fuser -v /dev/video4` と `ps` で `videohub_pc4` の専有を確認（**止めない・kill しない**） | 専有者を記録 | [ ] |
| H3 | 追加 USB カメラ（SunplusIT）は、**外した状態で G1 を起動し、内蔵映像が戻ってから挿す**（PR #34 `G1_USB_DUAL.md`）。`lsusb` と `/dev/v4l/by-id` に出るか | 出る。内蔵映像が落ちない | [ ] |
| H4 | `pyrealsense2`（system Python 3.8, 2.55.1）の `import` と `rs.context().devices`（videohub と競合しうるので、H2 の後に 1 回だけ） | 結果を記録（競合したら中止） | [ ] |
| H5 | `ROS_DOMAIN_ID` / `RMW_IMPLEMENTATION` / `CYCLONEDDS_URI`、librealsense・GStreamer の有無、OpenCV のビルド情報、Jetson の時刻とタイムゾーン（操作用 PC と約 1 時間ずれていた） | 値を記録 | [ ] |
| H6 | `camera_ctl.sh start → 映像確認 → stop → status` が「停止中」 | 停止中を確認 | [ ] |

守ること:
- カメラ配信サーバーは**手動で起動・停止するだけ**。常時起動・自動再起動（systemd / cron / ループ）は作らない。
- `videohub_pc4` は止めない（停止しても watchdog で再起動したという利用者報告がある）。
- G1 で `ros2 topic list` を叩かない（`bad_alloc` で失敗し、`_ros2_daemon` が約 7GB を使った）。死活確認は DDS を直接読む（PR #34 `Mapping/real/quickstart/probe_dds_topics.py`）。
- `camera_stream.py` は開けないカメラを 2 秒間隔で再 open し続ける。開けないときは `stop` する。
