# 次回 実機接続時の確認項目

PR #30（`Dev/UI` 向け）は、この一覧の **A〜C が済むまでマージしない**。
安全手順は `docs/g1-safety/`（2 人以上、`L2 + B` に手が届く、周囲を空ける、吊り下げ／着座から）。
結果は各行の `[ ]` に日付と値を書き込み、`docs/G1_FINDINGS.md` の未確認リストから消していく。

前提の確認: 電池 SOC 30% 以上（SOC 5% 未満は数分で停止する）／`ssh g1-ts`（または `g1`）が通る／
