# G1 Control モバイルUI

2026-10-24。承認済みの12画面モックを、Consoleの既存APIに接続した初回移行版。実装基準は `Dev/UI` の `c6c87d8`（リモコン受信表示・FSM 1001の調査記録を含む）。実機の機能追加ではなく、画面構成と入力の移行。ブラウザ自動操作・実機への書き込み・デプロイは行っていない。

## 入口と戻し方

- `/` と `/index.html`：新UI。初期画面は `#home`。
- `/legacy.html`：移行直前の従来UI。メニュー末尾から開ける。既存API・認証・設定ファイルを共用する。
- 模擬環境で見る：`python3 Console/server.py --mock --port 18792`。実機へは接続しない。
- 段階導入時は新UIを試し、問題があれば `/legacy.html` へ戻る。配備全体を戻す場合は旧リリースを使う。既存ハブの再起動・配備は別途行う。

## 12画面とAPI

| 新URL | 旧URL | 主な機能 |
|---|---|---|
| `#home` | 新設 | 接続・モード・バッテリー・鮮度、各画面への入口 |
| `#mode` | `#ops` | APIで定義されたモード、遷移、Speed 0/1、到達待ち・応答ログ |
| `#remote` | `#motion` | 操作権、方向・旋回ボタン、速度倍率、アナログ入力、運動停止 |
| `#actions` | `#action` | APIで許可されたwave・wave_turn・握手開始／終了 |
| `#status` | `#state` | 詳細の接続状態、脚・腕・リモコン、バッテリー・姿勢・基板・受信情報 |
| `#joints` | 同じ | 脚・腕・腰で選択する29関節、詳細と指令値の全表 |
| `#voice` | `#audio` | 読み上げ・音量・LED。認識・会話AIは未実装のまま |
| `#sensors` | `#camera` | カメラ・LiDAR・IMUの表示切り替え、配信プロセスの起動停止 |
| `#map` | 同じ | Nav地図・位置・経路、地点の登録・削除。Goal送信は行わない |
| `#tasks` | 同じ | 定義済みタスクの開始・停止・実行状態・ログ・結果 |
| `#dds` | 同じ | 台帳検索・選択詳細、購読・購読解除・許可された送信 |

旧URLも開ける。URLのハッシュとAPI名は今後同一とは限らない。APIのパス・スキーマは変更していない。

## 挙動と境界

- 共通表示は短いヘッダーと接続・モード・残量。詳細の接続カードは状態画面へ、自動確認の操作は設定へ移した。画面遷移は本文全体を切り替え、スクロールとフォーカスを先頭へ戻す。ブラウザの戻る・進むにも対応する。
- モード・アクション・機能の対応範囲はAPIを使う。既存の公式英語表記、遷移制限、速度試験、未確認情報と注意ダイアログを保持した。アクションの受理を動作完了とは表示しない。
- リモコンの方向ボタンは移動と旋回を同時に押せる。速度倍率は既存の各軸の上限に掛ける。モックの固定速度を送らない。
- 操作権取得後だけ入力を送る。指を離す・pointercancel・lostpointercaptureでその入力をゼロにする。画面移動・非表示・操作権喪失後は自動再開しない。取得待ちに画面を離れた場合、遅れて届いたセッションを解放する。
- 通信エラー時はブラウザの操作を終了する。ハブ側の途絶判定・クランプ・排他処理は既存のまま。物理的な停止は実機で別途確認が必要。
- センサー表示を離れたらストリーム・点群取得を止める。遅れた応答で表示接続を張り直さない。配信プロセスの起動は従来どおり明示操作で行う。
- タスクは取得したstate/result/logだけを表示する。モックの進捗率・一時停止・再開・地点からの移動生成は追加していない。実行中タスクには共通表示から戻れる。
- Nav presenceはマップ画面を見ている間だけ。画面移動時の振る舞いを変更していない。
- 新しい表示名と表示密度だけを `localStorage` に保存する。接続設定は既存の `POST /api/settings` に保存する。Domain IDや音声認識設定は追加していない。

## 構成と検証

- `web/index.html`：12画面と共通シェル。
- `web/mobile.css`：色・文字・余白・モバイルレイアウト。
- `web/ui-core.js`：既存のAPI／制御コード。画面遷移と遅延応答の処理を更新。
- `web/mobile.js`：ホーム表示、方向入力、部位選択、センサー切り替え、検索、表示設定。
- `web/legacy.html`：変更前のUIを保存。旧版への復帰用。
- サーバーは上記の固定ファイルだけを既存の認証ゲートの内側で配信する。任意のファイルパスを配信しない。
- `bash Console/tests/run_tests.sh`：既存の制御・認証・API・機能テストと、新しい静的配信・画面構造の検査。
- `node Console/tests/mobile_startup.cjs`：HTMLと両スクリプト全体をDOM形状の偽物で起動し、12画面の初期化と、画面遷移が機体操作を送らないことを検査。ブラウザでの見た目や実タッチの確認にはならない。
- `node Console/tests/mobile_runtime.cjs`：ブラウザを使わず実際の入力・ルート・操作権取得処理を実行。古い値、同時入力、画面移動後の遅延応答を検査。
