# 04. 次回確認したい項目

実機（ロボットがある場）で確認し、結果を [01](01-remote-control.md)〜[03](03-control-levels.md) に反映する。

## 1. ボタンのバージョン

- [ ] 自機は新版（`L2` 系）か旧版（`L1` 系）か。`L2 + B` で脱力するか、`L1 + A` で脱力するかで判定
- [ ] リモコンのシール（バージョン表記）を確認
- [ ] 旧版だった場合、通常操作・デバッグ・デバッグ確認のボタン（公式に記載なし）を特定

## 2. モード・`CheckMode`

- [ ] 通常モード時の `CheckMode` の値（`name`（`ai` など）と `form`）
- [ ] `GetFsmId` = 3102 の意味（デバッグ中に観測。公式の fsm 表で照合）
- [ ] ロックスタンド・通常操作での `GetFsmId` の値
- [ ] デバッグモードから通常モードへ戻す手順と、戻ったあとの `CheckMode`

## 3. デバッグモード

- [ ] 座位でデバッグモードに入れるか（公式は吊り下げのみ記載）。**吊り下げで先に確認**
- [ ] `L2 + A` の診断姿勢が、公式動画と一致するか
- [ ] LED が黄色になるか

## 4. 足首サンプル（`g1_ankle_swing_example.cpp`）

- [ ] 最初の「ゼロ位置へ戻す」が、脚だけか全関節か（ソースを読む）
- [ ] 吊り下げで、1 関節・小さいゲインから試す

## 5. `rt/arm_sdk`

- [ ] 使える状態（ロックスタンド、通常操作 1/2）で、重み（index 29）0→1 の補間を試す
- [ ] 内蔵のアーム制御サービスを止める手順（`34_arm_action_interface.md`）
- [ ] `rt/sportmodestate`（`fsm_id` / `fsm_mode`）が届くか（ファーム 1.5.1 以上）
