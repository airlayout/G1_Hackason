# 物理リモコンの機能整理と、コンソールの位置づけ

## 位置づけ

Web 開発コンソールは、**G1 付属の物理リモコン（R3）でできることを土台にし、それを拡張して、各種 SDK で実現する**もの。
リモコンは本体に直接入力する（SDK を通らない）ので、コンソールはリモコンの「操作の意味」を SDK の API に置き換えて再現する。

コンソールに持たせる基本機能と、現在の状態（2026-09-30）:

| # | 基本機能 | 状態 | 実機確認 |
|---|---|---|---|
| 1 | 接続状態表示（サーバー → Jetson → G1） | ✅ 実装済み | ⚠ 未確認（G1 電源オンでコンソールを通したことはない） |
| 2 | 自動再接続 | ✅ 実装済み（画面は 1 秒、Jetson 不通時は 3 秒間隔で再試行） | ⚠ 未確認 |
| 3 | モード変更 | ✅ 一部実装済み（6 種。下記） | ⚠ 未確認（`SetFsmId` は一度も実機で押していない） |
| 4 | アクション実行（手を振る等） | ❌ 未実装 | — |
| 5 | 矢印キーで移動 | ❌ 未実装 | — |
| 6 | バッテリー取得表示 | ❌ 未実装 | — |

**画面には、未実装の機能に「未実装」、実機で試していない機能に「実機未確認」と必ず表示する。**
状態の定義は [`modes.py`](modes.py) の `FEATURES` に一本化する（画面はそれを読んで描く）。

### ⚠ 過去のメモとの食い違い（未解決）

本コンソールの前提にしていたメモ（`README.md` の FSM 表の出典とは別の資料）には
「L2+B ダンピング、L2+Y ゼロトルク、L2+UP 固定立位、R1+X 通常歩行」とあったが、
**今回のマニュアル（R3 用）は L1 系**（ゼロトルク L1+B、ダンピング L1+A、固定立位 L1+UP）で、割り当てが一致しない。
リモコンの世代（R3 とそれ以前）の違いの可能性が高いが**確認していない**。
このコンソールはボタン割り当てではなく **FSM ID** を送るので動作には影響しない。ただし表を読む人は混同しないこと。

## 物理リモコン（R3）の仕様（マニュアル p.1–5）

| 項目 | 内容 |
|---|---|
| 通信 | デジタル伝送モジュール + Bluetooth。初回は Unitree Explore アプリの [設定] でリモコン ID を入力してバインド。以後は電源投入で自動接続 |
| 接続表示 | ロボットに繋がると右側の **DL** インジケータが点灯 |
| 到達距離 / 稼働時間 | 100 m 以上（開けた場所）/ 5 時間（780 mAh） |
| 電源 | 電源ボタンを短押し → 2 秒以上長押しで、ON（ビープ 2 回）/ OFF（ビープ 3 回） |
| 自動オフ | 電源オン後、ロボットにもアプリにも繋がらず無操作なら **10 分で自動的に切れる** |
| スティック校正 | スティックに触れず F1+F3 を同時に押して離す → ビープ（1 回/秒）→ 左右のスティックを全開で数回回す → ビープが止まったら F3 で確定 |
| 振動 / 音 | F3 を素早く 3 回で 振動⇔音 切替。F1 を素早く 3 回で 振動/音の ON⇔OFF。設定は既定で保存されず、保存するには電源オフ時に F1 を押し続ける |
| 充電・電池残量 | USB-C（5V/2A 推奨）。**リモコン自身の**電池残量は本体の LED 4 個（0–25 / 25–50 / 50–75 / 75–100 % / 満充電）で見る |

⚠ リモコンの電池残量は SDK からは取れない（物理 LED のみ）。コンソールが出すバッテリーは**ロボット本体**のもの。

## 操作機能（マニュアル p.5–11）

### スティックとキー（モード「メイン操作」中）

| 入力 | 動作 | 出典 |
|---|---|---|
| 左スティック 前 / 後 | 前進 / 後退（図に前後のみ描かれる。概要文には左右移動もあると記載） | p.5 |
| 右スティック 右 / 左 | 右旋回 / 左旋回（その場） | p.6 |
| Y / X | 立位の高さを上げる / 下げる | p.6 |
| B / A | 脚の上げ高さ（歩幅の足上げ）を上げる / 下げる | p.6 |
| START | 連続歩行 ⇔ 立位（スタンディング） | p.6 |

### 概念（p.7）

| 概念 | 説明 |
|---|---|
| ゼロトルクモード | 全モーターが能動動作を止める。揺らしても抵抗（ダンピング感）が無い |
| ダンピングモード | 全モーターが能動動作を止める。揺らすと明確なダンピング感がある。ここから準備モードへ入れる |
| **準備モード（Ready）** | 5 秒以内にゆっくりと、動作モード前の準備姿勢をとる。＝固定立位（`Lock stand`, L1+UP） |
| しゃがみモード | 5 秒以内にゆっくりしゃがむ（バランス制御なし） |
| 座位モード | 5 秒以内にゆっくり座る（バランス制御なし） |
| 動作モード | リモコンで移動を操作できるモード |
| 連続歩行モード | 常に足踏みしている |
| スタンディングモード | スティック入力が 0 なら足踏みを止めて立つ。入力が 0 でない、または外乱でバランスが崩れそうなときは足踏みを始める |
| **デバッグモード** | 下位開発用。SDK で開発・デバッグするときは、**モーション制御プログラムとの指令競合を避けるため、G1 をデバッグモードに入れる**。L2+A で入っているか確認できる |

### モード切替（p.8–9）

ボタン割り当て:

| 姿勢の切替 | ボタン |
|---|---|
| デバッグモード | L2 を押しながら R2 |
| ゼロトルク | L1 を押しながら B |
| ダンピング（①） | L1 + A |
| 固定立位＝準備（②） | L1 + UP |
| 座位（④） | L1 + LEFT |
| しゃがみ | L1 + DOWN |
| 寝た状態 ⇔ 立位（⑤） | L1 + X |
| しゃがみ切替（⑥） | L1 + Y |

遷移図（p.8 の図から読み取り。細部は原図で確認すること）:

```
電源ON → ゼロトルク ─L1+A→ ダンピング ─L1+B→ ゼロトルク
ダンピング ─L1+UP→ 準備(Ready) ─R1+X / R2+X→ メイン操作
ダンピング ─L1+DOWN→ しゃがみ     ダンピング ─L1+LEFT→ 座位
メイン操作 ─L1+A→ ダンピング（緊急停止の経路）
メイン操作 ─L1+DOWN→ しゃがみ / ─L1+LEFT→ 座位
寝姿勢 ⇔ メイン操作: L1+X       しゃがみ姿勢 ⇔ メイン操作: L1+Y
通常モードのダンピング ─L2+R2→ デバッグモードのダンピング
  デバッグ内: ダンピング ⇔ ゼロトルク（L2+B）、ダンピング ⇔ 診断動作（L2+A）
```

⚠ しゃがみ（L1+Y）でメイン操作から戻した後、電源を切らずにメイン操作へ戻すには、
L1+A（ダンピング）→ L1+Y の順に操作する（p.8 の注意書き）。

### 操作モード別のキー表（p.9–11）

マニュアルは表題の丸数字が重複している（③ が 2 つ）。以下は表題の文字どおり。

| モード | キー | 動作 |
|---|---|---|
| **R2+X（Run）** | B / A | 足上げ高さ 上 / 下 |
| | Y / X | 立位高さ 上 / 下 |
| | R1 + 左スティック | 低速走行 |
| | R2 + 左スティック | 高速走行 |
| **R1+X（メイン操作）** | START ダブルクリック | 足踏み継続（非推奨） |
| | START | 立位 |
| | L2 ダブルクリック / L1 ダブルクリック | 低速モード / 高速モード |
| | R1 を押しながら → / ← / ↓ / ↑ | 左 / 右 / 前 / 後のオフセット補正 |
| **R1+Y（腰 3 自由度の機体のみ）** | START ダブルクリック / START | 足踏み継続（非推奨）/ 立位 |
| | L2 / L1 ダブルクリック | 低速 / 高速モード |
| | R1 を押しながら → / ← / ↓ / ↑ | オフセット補正（R1+X と同じ表記） |
| **R2+Y（腰 3 自由度の機体のみ）** | B / A / Y / X | 足上げ高さ 上 / 下、立位高さ 上 / 下 |
| | START | 足踏み継続（非推奨）/ 立位 |
| | SELECT を押しながら右スティック | **腰の制御** |

腰 3 自由度の機体では R1+Y モードの使用が推奨されている（p.10）。この機体は `GetFsmId=501` を返した。
README の FSM 表では 501 を「腰 3 軸の通常歩行」としているので、R1+Y 系の表がこの機体に対応する見込みだが、**推測**。

### 起動手順と注意（p.10–11）

- 通常起動: 電源 → ①ダンピング → ②固定立位 → ③メイン操作 →（デモ）→ ④座位 → 電源オフ
- 寝姿勢からの起動: ① → ⑤ → デモ → ⑥ → 電源オフ（**股のポストが地面と水平**であること）
- しゃがみ姿勢からの起動: ① → ⑥ → デモ → ⑥ → 電源オフ
- 寝姿勢・しゃがみ姿勢からの起動は**平らで硬い地面のみ**。他の場所では立ち上がりが不安定
- 器用ハンド装着時は、寝姿勢・しゃがみ姿勢の起動でハンドを壊しやすい
- **現在の歩行モードに階段を登る機能は無い**。階段を登らせない
- 壁・ドアなどの障害物はリモコンの電波を大きく弱める。開けた場所で使う

## 矢印キー移動の案（未決定・未実装）

リモコンのスティック相当をキーに割り当てる案。**議論して決める**。

| キー | 案 |
|---|---|
| ↑ / ↓ | 前進 / 後退（`vx`）。左スティックの前後相当 |
| ← / → | 左 / 右への横移動（`vy`）。左スティックの左右相当 |
| Q / E | 左 / 右への回転（`omega`）。右スティック相当。**並進とは別キー** |
| 上記の同時押し | 合成（斜め移動しながら回転など）。逆向きの同時押しは相殺して 0 |
| キーを離す・フォーカスが外れる・通信が途切れる | 直ちに停止（`StopMove`） |

安全側の設計: 送るのは**短い duration（例 0.3 秒）の `SetVelocity` を繰り返す**方式にする。
コンソールが落ちても、Jetson が切れても、最後の指令の duration が切れれば止まる。
移動は「メイン操作」モードのときだけ有効にする。
