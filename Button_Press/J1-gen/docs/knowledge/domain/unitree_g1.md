# Unitree G1（機体）の知識

## 頭カメラの向きは、首の傾きで変わる

- **日付**: 2026-10-22（ユーザーの訂正）
- **プロジェクト**: G1 ボタン押し（同じリポジトリで G1 の頭カメラを使う Mapping・Navigation にも関係する）
- **前提バージョン**: G1 29DoF（mode_machine 5）、頭カメラ RealSense D435i、URDF は unitree_ros の g1_29dof_rev_1_0（d435_joint の pitch 47.6°）
- **状況**: 2026-10-14 は深度から求めた頭カメラの向きが水平から 45.9° 下、2026-10-21 は 71° 下だった（立った状態、骨盤は水平）
- **原因**: 10/21 は首が傾いていた。通常の向きは約 45° 下で、URDF の 47.6° とほぼ同じ
- **対処**: 作業の初めに、立った状態で頭カメラの向きを確かめる（`real/check_head_tilt.py`。深度から床・机の面を見つけて pitch を求める）。
  ずれていれば首の傾きを直して測り直す。直せないときだけ、実機用のカメラ設定（`configs/camera.yaml` の `head_camera_mount`）で上書きする
- **教訓**: G1 の頭カメラの外部パラメータは固定と考えない。24° ずれると、体の座標で求める対象の位置が 20 cm 以上ずれる

## 純正の歩行コントローラは、遅い指令では歩き出さない（班の Navigation の実測、2026-09-09。Button_Press の寄る流れで使う）
- vx 0.1 は関節が少し動くだけ、0.2 は歩くが進む向きが定まらない（+98.6° ずれた）、0.3 で前に進む（1 秒で約 23 cm、向きは −18〜−20° ずれる）。
  角速度は 0.02 で動かず、0.3 で回る（出典: `Navigation/nav2_stable/Planning.md` の U-07・U-12）
- `LocoClient.SetVelocity(vx, vy, ω, duration)` の duration が終わると自分で止まるが、約 1.9 秒は歩き続ける（完全に止まるまで 3.4 秒）。
  `Move(..., continous_move=True)` は duration が約 10 日になるので使わない
- 横・回る・1 秒未満の時間は、まだ誰も測っていない（`real/loco_pulse.py` で測る）
