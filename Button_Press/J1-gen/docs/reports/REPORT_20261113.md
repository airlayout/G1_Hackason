## 予想と違ったこと → 原因 → どう確かめたか → 何を変えたか

- **頭カメラが空の画像を返した** → ロボットの起動直後に、Unitree の videohub がカメラをつかみ損ねたと思われる（確かめていない）
  → 3 分待っても空のまま。カメラ自体は USB で見えていた → ロボットを再起動して直った。次から、起動直後に 1 枚取れるかを先に見る
- **マイクの「途切れ 31 回」** → 1 パケットが 0.16 秒分の音で、途切れとみなす 0.1 秒を毎回超えていた（実際の欠けは無い）
  → 5 秒で 5.1 秒分が届いていた → スクリプトの判定を直す（まだ）
- **押した力の推定が空中でも 6〜9 N** → 腕を前へ伸ばすほど増えるので、重力の計算と実機の差など、姿勢によるずれと思われる
  → 空中で 3 回（左 2・右 1）送って、どれも同じくらい出た → 空中での値を引くなどの直し方を机の上で考える。それまで力の推定で「押せた」とは判断しない
- **左腕を送った 1 回目、動いたのに「動いていない気がする」** → 切り離して起動したので始まりの合図が無かった
  → 関節角の記録で動いていたのを確かめた → 送るコマンドは自分で打ち、Claude は dry-run までにした
