# 追従者ゴーストを地図から消す

MOLA の地図（`nav_map_ref` の元）には、建図中に機体についてきた人が**焼き込まれている**。
ここはそれを消す道具一式。**基準地図は掃除してはいけない**（`make_ref_map.py` の注記）が、
**人は「地図が知っている物」ではない**ので別扱いにする。

## 使い方

```bash
cd Mapping/real
../../Navigation/.venv/bin/python quickstart/ghost/run_all.py     # 3 案と合わせ技を比べる
../../Navigation/.venv/bin/python quickstart/ghost/render_figs.py # 図を 2 枚
```

成果物（候補地図・キャッシュ・ログ）は `runs/ghost_eval_20260912/` に出る。
⚠️ **`runs/` は `.gitignore` の対象**。道具はこちら（`quickstart/`）に置くこと。
2026-09-12 の一式は `/private/tmp` にしか無く、危うく消えるところだった。

## ファイル

| ファイル | 何をするか |
|---|---|
| `score.py` | **共通のスコアカード。**合否はここ 1 箇所。**主指標は壁の帯**、合否は **09-10 の記録だけ**で出す |
| `filters.py` | 3 つの手。`tube`（軌跡）/ `blob`（人の形）/ `carve` は `run_carve.py` 側 |
| `run_tube.py` / `run_blob.py` / `run_carve.py` | 各案の掃引 |
| `run_all.py` | 3 案の最良と合わせ技を 1 枚で比較 |
| `render_figs.py` | 前後の図と、手ごとの除去範囲の図 |
| `build_history.py` | ボクセルごとの観測履歴を `.npz` に（**持続性フィルタは棄却済み**。履歴自体は診断に使える） |

## 3 つの手と、効く／効かない場所

| 手 | 証拠 | 効く | 効かない |
|---|---|---|---|
| `tube` | 機体が**通り抜けた** | 通り道に居た追従者（A で 71.6 %） | 通り道から外れた人 |
| `blob` | **人の形で、上に支えが無い** | 孤立して立っている人（B で 43.9 %） | smear になった追従者（A で 8.3 %） |
| `carve` | 後の光線が**貫いた** | 見通せた所（B で 22.6 %） | 一度も見通していない所 |

合わせ技で **A 72.0 % / B 59.0 %**。壁の帯は 92.9 % で 1 桁も動かない。

## ⚠️ 踏んだ罠（同じ穴を掘らないこと）

- **持続性（最遠 × 時間幅）では切れない。**30 通り掃いて全部で机が先に消えた（2026-09-12）
- **「1.9 m より上に点があれば構造」は天井を拾う。**占有セルの 53 % が構造扱いになる。
  支えは**帯 1.9–2.3 m** で見る（2026-09-13）
- **合否はフィルタが見ない記録で測る。**同じ記録だと素通りする（2026-09-13）
- **距離で「机」を定義しない。**軌跡 1.1 m 脇に立っていた人を机として数えた（2026-09-12, 09-13 に 2 度）
- **彫りは外れだけ数えない。**当たりも数えて比で判じる（OctoMap の log-odds と同じ）
- **入力は `map_full_raw.txt`。**`map_full_p.txt` は棄却された持続性フィルタの出力
