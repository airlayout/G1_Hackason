# 実測値（2026-10-01）

**すべて実機から読んだ値。推測は含めない。**
ログファイルは `.gitignore` で除外されるため、必要な値をここに転記している。

機体: G1 29自由度 / `mode_machine=5` / 吊り下げ（足は接地）

---

## 通信

| 項目 | 実測 |
|---|---|
| `rt/lowstate` 受信レート | **1040〜1047 Hz**（3秒で3120件） |
| `rt/lowcmd`（`ai` 稼働中） | **991〜1002 Hz** — ロボット自身の制御が占有 |
| `rt/lowcmd`（デバッグ状態） | **0.0 Hz** — 空き |
| `rt/lowcmd`（teleop 稼働中） | **240〜247 Hz** |
| 有線リンク | 1000Mb/s Full（ハブ経由） |
| 有線 ping | `192.168.123.161` / `.164` ともパケットロス 0% |

`rt/lowcmd` の writer は `ai` 稼働中 **2本**、`rt/arm_sdk` に **1本**（0 Hz・待機）、
`rt/lowstate` は **1本**。

## `ai` 解除の前後

| | `rt/lowcmd` | 腕 mode | 脚 mode | 腰 mode |
|---|---|---|---|---|
| 解除前 | 1000.7 Hz | 1 | 1 | 1 |
| 解除後 | **0.0 Hz** | **0** | **0** | **0** |

解除直後の8秒間、`mode=0` のまま変化なし。脚トルクは 0.36〜0.53 Nm で支持状態を維持。

**RPC の失敗:** 1回目は6回連続で `status=3104`（送信成功・返事なし）。
2回目の実行で成功した。

## 指令で通電できるかの試験（できなかった）

teleop が送信中の状態で、送信内容と実測モードを12秒間観測した。

```
  [ 2s] lowcmd=  246Hz  送信mode=[1] kp=80  →  実測mode=[0]
  [ 4s] lowcmd=  247Hz  送信mode=[1] kp=80  →  実測mode=[0]
  [ 6s] lowcmd=  246Hz  送信mode=[1] kp=80  →  実測mode=[0]
  [ 8s] lowcmd=  246Hz  送信mode=[1] kp=80  →  実測mode=[0]
  [10s] lowcmd=  246Hz  送信mode=[1] kp=80  →  実測mode=[0]
  [12s] lowcmd=  246Hz  送信mode=[1] kp=80  →  実測mode=[0]
```

**teleop は `motor_cmd[].mode=1` を正しく送っているのに、モータは通電しない。**
通電はリモコンのFSM（ダンピング）でしか行えない、という既知の制約を実測で確認した。

`watch_and_launch.py` による自動起動の実績。

|---|---|---|
| 1回目 | 71.7 秒 | 検出と同時（0.05秒以内） |
| 2回目 | 232.9 秒 | 同上 |
| 3回目 | 259.0 秒 | 同上 |


## トルク（負荷の目安）

| 状態 | 腕トルク最大 | 脚トルク最大 |
|---|---|---|
| 脱力（`mode=0`） | 0.19 Nm | 0.35〜0.70 Nm |
| teleop 保持中（追従前） | 0.06 Nm | 0.26 Nm |
| 追従中 | **8.44〜10.25 Nm** | **5.45〜9.93 Nm** |

追従中に脚トルクが上がるのは、teleop が**全29関節を固定している**ため
（脚 kp=300）。腕を動かすと吊り下げの機体が揺れ、脚がそれに抵抗する。
脚関節の能力に対して十分小さい。

## kp / kd（teleop が設定する値）

| 対象 | kp | kd |
|---|---|---|
| 腕（手首以外） | 80 | 3.0 |
| 手首 | 40 | 1.5 |
| 脚・腰 | **300** | 3.0 |

腕の速度上限は起動時 **2 rad/s**（`safe-startup` パッチ）、
追従開始で **30 rad/s** へ戻る（`speed-restore` パッチ）。

## 停止

```
応答 {'status': 'ok', 'msg': 'ok'}

rt/lowcmd       0.0 Hz        誰も指令していない
腕mode=[0] 脚mode=[0]         脱力（終了時の既定）
腕トルク 0.19〜0.31 Nm / 脚 0.35〜0.44 Nm
teleop プロセス停止・ポート8012 解放
```

終了時に両腕はゼロ姿勢へ戻る。捻れていた左腕（肩Yaw −76°、手首Roll −93°）も
**肩Yaw −0°、手首Roll −1°** まで戻り、右腕と左右対称になった。

| | 肩Pitch | 肩Yaw | 肘 | 手首Roll |
|---|---|---|---|---|
| 左 | −0° | −0° | +48° | −1° |
| 右 | −4° | −0° | +54° | −1° |
