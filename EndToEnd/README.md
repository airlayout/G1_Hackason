# EndToEnd

Unitree G1 の End to End ニューラルネットワーク制御を開発する領域。
現在はディレクトリ構成のみを用意しており、入力・出力、学習方式、実行環境は今後決定する。

## 構成

| ディレクトリ | 役割 |
|---|---|
| `src/g1_e2e/` | NNモデル、観測の前処理、シミュレーションと実機で共通の推論処理 |
| `train/` | データ収集・学習 |
| `sim/` | シミュレーションとの接続・評価 |
| `real/` | 実機との接続・実行 |
| `configs/` | 学習・推論の設定 |
| `tests/` | 入出力や実装の検証 |

## 開発方針

- 依存関係は `pyproject.toml` で管理し、このディレクトリ専用の環境を使う。
- 既存機能との接続は `sim/`・`real/` にまとめ、NN本体から通信やシミュレーターの詳細を分離する。
- データセット・重み・実験ログは `datasets/`・`checkpoints/`・`runs/` に保存し、Git管理外とする。
  再取得先、学習設定、使用したコードのコミットを記録して再現できるようにする。

実行手順と依存パッケージは、実装時に追記する。
