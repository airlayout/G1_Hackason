# 安全管理資料(Phase A-8)

Planning.md §7「実機試験の安全前提」を、実際に現場で使えるチェックシート・手順書に
落とし込んだもの。Phase 0（接続性検証）着手前に、このフォルダの内容を関係者全員で
確認しておくこと。

## 大原則(Planning.md §7から抜粋・強調)

1. **純正リモコンまたは物理停止手段を、いつでも即座に使える状態に保つ。**
   ソフトウェアE-stopは通信が生きていることが前提の機構であり、通信断では無力。
2. **速度は低速から段階的に上げる。** 各段階の合格を確認してから次に進む。前の段階を
   飛ばさない。
3. **停止担当者を明示的に指名する。** 「誰かが見ている」ではなく「この人が止める」を
   決めておく。
4. **全ての停止イベントを記録する。** 時刻・状態・停止理由・最後の指令・SDK結果。
   `incident_log_template.md` を使う。
5. **異常時に自動でDamp/ZeroTorqueへ遷移させない。** まずゼロ速度。モード変更は
   操作者の明示操作(D-13)。

## Phase Aでの位置づけ

この資料自体は実機なしで作成できる（Phase A-8）。ただし内容の一部（試験区域の具体的な
選定、実際の人員割り当て）は実機到着後・現地確認後に確定する項目を含む。該当箇所には
「現地確認要」と明記してある。
