# 役割定義

実機試験時は、以下の役割を**試験開始前に**割り当てる。1人が複数役を兼ねてよいが、
**停止担当者だけは他の作業(記録・操作)に気を取られない専任にする**。

## 役割一覧

| 役割 | 人数 | 責務 |
|---|---|---|
| **停止担当者** | 1名(専任) | 純正リモコンを常時手に持ち、異常があれば即座に停止操作をする。他の作業をしない。試験中はG1から目を離さない |
| **操作者** | 1名 | PC/端末からteleopまたはNavigationの指令を出す。Goal投入、Enable/Disable操作 |
| **観察者** | 1名以上 | G1の挙動(歩容の乱れ、異音、ケーブルの状態等)を目視監視する。異常の兆候があれば停止担当者に即座に声をかける |
| **記録者** | 1名(操作者と兼任可) | `incident_log_template.md` に沿って停止イベント・試験結果を記録する |

最小構成は**停止担当者+操作者の2名**。観察者・記録者は操作者が兼任してもよいが、
**停止担当者の専任は譲らない**。

## 停止担当者の権限

- **停止担当者は、他の誰の指示も待たずに独断で停止操作をしてよい。** 「止めていいか確認する」
  時間が事故につながる。止めてから説明する
- 停止担当者が「止める」と判断したら、操作者は即座に指令送信を止める(Nav2 Goalキャンセル・
  teleop停止)。両方止める(仕様書8章の優先順位: 物理E-stop・純正リモコンが最優先)
- 段階試験(Phase 1)でG1を安全支持している間も、停止担当者は気を抜かない
  (支持具の不具合・想定外の反力など)

## 事前確認(試験開始前に停止担当者が必ず行う)

- [ ] 純正リモコンの電池残量・通信確認
- [ ] 純正リモコンでの停止操作を実際に1回試す(空撃ちでよい。G1が反応することを確認)
- [ ] 自分がどのボタン/操作で止めるかを声に出して確認する
- [ ] 試験区域からの退避経路を確認する
