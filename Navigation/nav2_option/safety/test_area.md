# 試験区域の選定基準・立入管理手順

## 選定基準

Planning.md D-24（MVPは床に低い障害物のない管理された区域に限定）と、頭部LiDAR(MID-360)の
死角特性([Planning.md §2](../Planning.md)参照: 垂直視野-7°〜+52°、足元〜約10m先の床が死角)を
踏まえる。

| 項目 | 基準 | 理由 |
|---|---|---|
| 床面 | 平坦。段差・スロープ・ケーブル類なし | 仕様書スコープ外(段差踏破は対象外) |
| 障害物 | 低い障害物(50cm未満)を置かない。特にPhase 0〜2bでは**何も置かない**のが望ましい | MID-360は50cm未満の障害物を検知できない(既存Navigation班README実測に基づく)。加えて足元の死角があるため、低い障害物は原理的に見えない |
| 面積 | 最低5m×5m以上。Phase 2c以降のGoal到達試験には10m×10m程度あるとよい | 停止距離(U-08で実測)・旋回半径に余裕を持たせる |
| 天井高 | 2.5m以上 | MID-360の垂直視野+52°が天井に当たらないようにする(実測確認要) |
| 床材 | 滑りにくい material | 二足歩行の安定性に影響する。実機到着後に確認 |
| 周囲 | 壁または柵で囲まれ、部外者が予告なく立ち入れない | 立入管理の基本 |
| 電源 | 充電設備、有線LAN(D-XX有線接続を推奨する場合)の引き込みが可能 | Planning.md U-07の結果次第で有線LAN必須になる可能性がある |

**現地確認要**: 実際の試験場所は、上記基準を満たす候補を実機到着前に選定しておき、
実機到着後に天井高・床材・電源を現地で確認する。

## 立入管理手順

### 試験開始前

1. 試験区域の入口すべてに「試験中・立入禁止」の表示を出す
2. 部外者が入りうる経路(隣接する扉、通路)を把握し、必要なら追加の表示・簡易柵を設置する
3. 停止担当者・操作者・観察者以外は区域外に退避させる
4. 見学者がいる場合は、区域の外周(G1の可動範囲+停止距離の余裕分)から出ないよう明示する

### 試験中

- 区域内への入退室は停止担当者に一声かけてから行う(集中を妨げない範囲で)
- 予期しない人・物の侵入を検知したら、**声を出して停止担当者に伝える**(観察者の役割)

### 試験終了後

1. G1を安定した停止状態にしてから試験終了を宣言する
2. 表示・柵を撤去する
3. `incident_log_template.md` の記録を回収する

## 段階別の追加基準

| フェーズ | 追加基準 |
|---|---|
| Phase 0〜1前半 | G1を安全支持具で固定した状態で実施。区域面積の要件は緩和可 |
| Phase 1後半(段階3〜8) | 低速(0.5m/s未満)での直進・旋回試験。区域内は完全に空にする |
| Phase 2c(Nav2接続) | 静的障害物試験を行う場合のみ、50cm以上の障害物を1個だけ置く。複数の障害物や低い障害物は置かない(死角の影響を受けるため) |
